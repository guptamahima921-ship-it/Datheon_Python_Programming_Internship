# Datheon Python Programming Internship

## About

This repository contains the projects completed as part of my Python Programming Internship at Datheon.

## Projects

### 1. Investment Portfolio Tracker

- Python-based investment portfolio tracking project.
- Uses a CSV dataset to store portfolio information.
- Uses the `yfinance` library to retrieve stock market information.
- Calculates invested value, current value, profit and loss.
- Generates a portfolio summary.

**Main files:**
- `portfolio.py`
- `portfoliyo.csv`

### 2. Automatic File Organizer

- A Python project that automatically organizes files into folders based on their file types.
- Uses Python libraries such as `os`, `shutil`, and `pathlib`.
- Organizes files into categories such as Documents, Images, Videos, Archives, Code, and Others.

**Main file:**
- `organizer.py`

### 3. Hangman Game

- A Python implementation of the Hangman word-guessing game.
- Uses a text file containing English words.
- Includes the game source code and supporting files.

**Main files:**
- `Hangman-Gam.py`
- `google-10000-english-no-swears.txt`
- `AIML project excel sheet.xlsx` (company-provided project file)

## Technologies Used

- Python
- CSV
- yfinance
- os
- shutil
- pathlib

## Installation

Install the required library using:

~~~bash
pip install yfinance
~~~

## Running the Projects

**Investment Portfolio Tracker:**

~~~bash
python portfolio.py
~~~

**Automatic File Organizer:**

~~~bash
python organizer.py
~~~

**Hangman Game:**

~~~bash
python Hangman-Gam.py
~~~

## Learning Outcomes

Through these projects, I gained practical experience in Python programming, file handling, working with datasets, using Python libraries, and developing small real-world applications.
